*Sistema de Estoque

Sistema de gerenciamento de estoque desenvolvido em C como projeto prático de programação.

*Sobre o projeto

O sistema permite realizar operações básicas de gerenciamento de produtos, utilizando conceitos fundamentais da linguagem C.

*Funcionalidades

- Cadastrar produtos
- Listar produtos
- Buscar produtos pelo código
- Alterar informações dos produtos
- Excluir produtos
- Impedir o cadastro de códigos duplicados
- Limitar o estoque a 100 produtos

*Conceitos utilizados

- Structs
- Vetores
- Funções
- Ponteiros
- Estruturas condicionais
- Estruturas de repetição
- Manipulação de strings
- Entrada e saída de dados

*Tecnologias

- Linguagem C
- GCC
- Git
- GitHub
